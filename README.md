# Конституція та кодекси України з історією змін

Репозиторій згенеровано інструментом `jurik` з офіційних джерел. Гілка `main` = чинний
текст Конституції та кодексів України, по одному markdown-файлу на статтю; історія комітів =
історія законів, що їх змінювали.

**Це не офіційна публікація.** Офіційний текст: zakon.rada.gov.ua. Можливі помилки
розбору, неточна атрибуція правок (див. «Обмеження»).

## Джерела

- Тексти редакцій: «Законодавство України», https://zakon.rada.gov.ua (через відкритий
  API https://data.rada.gov.ua/laws/).
- Законопроекти, ініціатори, дати, голосування: відкриті дані Верховної Ради України,
  https://data.rada.gov.ua.

© Верховна Рада України. Умови використання обох джерел вимагають посилання на джерело:
у разі поширення цих текстів чи похідних від них даних зазначайте zakon.rada.gov.ua та
data.rada.gov.ua.

## Структура

```
README.md
codes/<код>/
  _meta.yaml          назва, zakon_id, дата прийняття, посилання, статус
  preamble.md         преамбула (текст до першого структурного рівня)
  closing.md          підпис, місце та дата ухвалення
  NN-<назва>/         структурний рівень: книга, частина, розділ, підрозділ, глава, §
    provisions.md     заголовок рівня та його текст поза статтями
    art-NNNN.md       стаття
bills/<скликання>/<номер>.md   лише в гілках законопроектів без злиття
```

- Номер законопроекту в шляху і в назві гілки записано ASCII: `1234-д` →
  `bills/4/1234-d.md`, гілка `bill/4/1234-d`.
- Редакцію zakon, з якої взято текст, називає трейлер `Edition:` коміту `main` (у
  `_meta.yaml` її немає).

- Номер папки береться з номера в джерелі, а не з порядку: римські цифри → арабські
  (`Розділ XIV` → `14-…`), індекс зберігається (`Глава 1-1` → `01-1-…`, `Глава III-А` →
  `03-a-…`). Назва папки = транслітерація заголовка (КМУ-2010, до 40 символів).
- Стаття: `art-0014.md`, з індексом `art-0039-1.md`, `art-0096-10-1.md`. Якщо джерело
  містить дві статті з однаковим номером поспіль, друга лежить у файлі з суфіксом `_2`
  (`art-0183-7_2.md` у КАС 2016–2017), заголовок зберігає номер з джерела.
- Кожен рівень має `provisions.md`, що починається з заголовка рівня (`# Розділ I. …`);
  ненумеровані пункти перехідних і прикінцевих положень лежать у ньому як є.
  Ненумеровані «ПРИКІНЦЕВІ ТА ПЕРЕХІДНІ ПОЛОЖЕННЯ» (ЦК) мають папку без номера;
  ненумеровані підзаголовки всередині § (ЦК, «2. Повне товариство») і «II. ОСОБЛИВА
  ЧАСТИНА» КУпАП теж є рівнями зі своїми папками.
- Виключена стаття не видаляється: файл містить `# Стаття N. Виключена`.
- Редакторські примітки zakon у фігурних дужках `{…}` до тексту не входять: їх зміст
  передають коміти.
- КУпАП на zakon складається з двох документів (80731-10, 80732-10); у папці
  `admin-offences` вони об'єднані.
- Кодекс, що втратив чинність, видаляється з `main` комітом `Reason: repealed`; його
  історія лишається в git.

## Модель історії

- `main` упорядковано за датою **набрання чинності** редакцій. Кожен коміт `main` має
  трейлер `In-force:`; стан на дату = останній коміт `main` з `In-force:` ≤ цієї дати
  (не `git log --before`).
- Дата коміту (author/committer date) злиття = дата **прийняття** закону, тому вздовж
  `main` вона може йти не по зростанню.
- Перший коміт кожного кодексу (`Reason: initial`) = найраніша редакція на zakon. Для
  старих кодексів (КЗпП, Житловий, КУпАП тощо) це зведений текст, а не текст при
  прийнятті. Його `In-force:` = дата набрання чинності кодексом, якщо вона пізніша за
  дату редакції (Податковий: редакція 02.12.2010, `In-force: 2011-01-01`); так само
  датовано редакції, що з'явилися до набрання чинності.
- Закон, що змінив кодекси, = гілка `bill/<скликання>/<номер законопроекту>` (номер ASCII:
  `1234-д` → `1234-d`) з комітом правок і злиттям у `main`. Гілка відходить від `main`,
  чинного на дату реєстрації законопроекту, або пізніше: від останнього коміту `main`,
  що змінював ті самі файли (і не раніше першого коміту кодексу). Тому `git diff
  bill/…^ bill/…` = `git show --first-parent <злиття>` = лише правки цього закону, а
  `git log`/`git blame` статті бачать усі закони, що її змінювали. Автор коміту гілки =
  перший ініціатор (`<slug>@deputies.invalid`, решта = `Co-authored-by:`); автор злиття =
  Верховна Рада України.
- Закон, що набирає чинності частинами (різні дати `In-force:`), = кілька комітів однієї
  гілки (`Stage: 1`, `2`, …) і кілька злиттів.
- Редакція з кількома підставами, а також редакції різних кодексів однієї дати зі
  спільною підставою = один коміт з кількома `Law:` (`Reason: multiple`); гілка названа
  за законом, що вже має гілку, інакше за першим за номером; правки не розділяються.
- Якщо назва гілки вже зайнята іншим законом чи законопроектом, додається суфікс `-2`.
- Закон без законопроекту у відкритих даних (переважно до 1998 року): гілка
  `bill/law/<номер закону>`, `Bill: unknown`.
- Рішення Конституційного Суду (`Reason: court`), редакції без підстави
  (`Reason: unknown`) чи з підставою, що не є законом (`Reason: other`), = лінійні коміти
  `main`.

### Гілки `bill/*` без злиття

**Увага:** гілки `bill/*`, не злиті в `main`, = законопроекти, що **не стали законом**
(відхилені, відкликані, зняті з розгляду, на розгляді). Вони не є чинним правом. Їх
єдиний коміт додає `bills/<скликання>/<номер>.md` з текстом законопроекту (або
«Текст недоступний» з посиланням на картку); статті кодексів не змінюються.
Список: `git branch --no-merged main --list 'bill/*'`.

### Трейлери комітів

| Трейлер | Де | Значення |
|---|---|---|
| `Law:` | `main`, гілки | номер закону, напр. `2856-VI` |
| `Bill:` | `main`, гілки | `<скликання>/<номер>` законопроекту або `unknown` |
| `Adopted:` | `main` | дата прийняття, голоси «в цілому» (за / проти / утрималися) |
| `Signed:` | `main` | дата підписання |
| `In-force:` | `main` | дата набрання чинності редакції (вісь часу) |
| `Stage:` | `main`, гілки | етап набрання чинності того самого закону |
| `Reason:` | `main` | `initial`, `law`, `multiple`, `court`, `unknown`, `other`, `repealed` |
| `Basis:` | `main`, гілки | підстава, що не є законом (рішення КСУ тощо) |
| `Edition:` | `main` | редакція zakon: `<zakon_id>/edYYYYMMDD` |
| `Source:` | `main`, гілки | посилання на закон або картку законопроекту |
| `Registered:` | гілки | дата реєстрації законопроекту |
| `Status:` | гілки без злиття | `rejected`, `withdrawn`, `removed`, `pending` |
| `Status-date:` | гілки без злиття | дата поточного стану законопроекту |

## Як читати

```
# закони в порядку набрання чинності
git log --first-parent main
# історія статті
git log --follow -- codes/tax/01-zahalni-polozhennia/art-0014.md
# який закон змінив рядок
git blame -- codes/constitution/01-zahalni-zasady/art-0005.md
# правки закону та стан на дату (останній коміт з In-force <= дати)
git show <коміт злиття>
git log --first-parent --format='%h %(trailers:key=In-force,valueonly) %s' main
```

## Обмеження

- Правки однієї редакції з кількома підставами не розділяються між законами.
- Якщо на zakon немає окремої редакції для закону (подія є в історії картки, редакції
  немає), його правки потрапляють у коміт наступної редакції під її підставою.
- Законопроекти до кодексів знайдено за назвою; «комплексні» законопроекти («до деяких
  законодавчих актів»), що не називають кодекс, не враховано.
- Тексти законопроектів у форматі Word 97 (`.doc`) не конвертуються.
- У цій збірці гілок законопроектів без злиття не більше 500 (найраніше зареєстровані); решта не включена.
