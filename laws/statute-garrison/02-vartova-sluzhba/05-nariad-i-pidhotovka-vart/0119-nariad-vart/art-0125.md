# Стаття 125.

За наявності постів, що охороняються вартовими собаками, для несення служби призначається помічник начальника варти із служби вартових собак із числа старших вожатих вартових собак (додаток 17 до цього Статуту).

( Стаття 125 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
