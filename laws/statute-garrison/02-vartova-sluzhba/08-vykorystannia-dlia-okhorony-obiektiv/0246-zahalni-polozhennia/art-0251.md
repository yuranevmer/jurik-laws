# Стаття 251.

Автомобіль (БТР, БМП), на якому пересувається контрольно-охоронна група, обладнується розпізнавальними різнокольоровими вогнями (додаток 15 до цього Статуту), чатові на постах повинні знати кольори розпізнавальних вогнів.

( Стаття 251 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
