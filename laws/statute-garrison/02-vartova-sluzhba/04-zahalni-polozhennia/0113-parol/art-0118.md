# Стаття 118.

У разі розсекречення пароля його дія негайно припиняється, про що доповідається заступникові начальника гарнізону (начальникові штабу військової частини). Начальникові варти новий пароль вручається черговим варт (військової частини) або його помічником у вартовому приміщенні.

( Стаття 118 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
