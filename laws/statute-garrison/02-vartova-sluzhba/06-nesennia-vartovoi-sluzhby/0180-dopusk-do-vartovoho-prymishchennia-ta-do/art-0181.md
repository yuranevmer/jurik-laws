# Стаття 181.

Усі особи, що прибули для перевірки варти, показують разове посвідчення на право перевірки варти (додаток 9 до цього Статуту), видане начальником або військовим комендантом гарнізону (командиром військової частини), та посвідчення особи. Без посвідчення варту можуть перевіряти лише особи, визначені в статті 209 цього Статуту.

( Стаття 181 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
