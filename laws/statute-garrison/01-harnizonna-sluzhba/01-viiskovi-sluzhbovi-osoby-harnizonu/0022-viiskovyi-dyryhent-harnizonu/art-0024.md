# Стаття 24.

У разі виникнення у військових частинах, гарнізонних вартах і гарнізонних об'єктах пожежі, стихійного лиха чи надзвичайної події начальник органу управління Служби правопорядку в гарнізоні зобов'язаний прибути на місце пожежі, стихійного лиха чи надзвичайної події для вжиття необхідних заходів. ( Стаття 24 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
