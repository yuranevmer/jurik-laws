# Стаття 11.

Під час прибуття до гарнізону вищих офіцерів для виконання службових завдань, прямих начальників із питань гарнізонної та вартової служб начальник гарнізону відрекомендовується лише старшим за військовим званням вищим офіцерам. ( Частина перша статті 11 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )

У разі вибуття з гарнізону начальник гарнізону покладає свої обов'язки на заступника начальника гарнізону, про що він оголошує в наказі по гарнізону та доповідає командувачеві військ оперативного командування. ( Частина друга статті 11 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
