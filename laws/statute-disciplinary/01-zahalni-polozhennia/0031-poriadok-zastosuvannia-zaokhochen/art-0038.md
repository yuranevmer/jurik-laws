# Стаття 38.

Повідомлення батьків або колективу за місцем роботи чи навчання військовослужбовця до його призову на службу про зразкове виконання ним військового обов'язку та про одержані заохочення застосовується до військовослужбовців строкової військової служби та курсантів військових навчальних закладів.

( Стаття 38 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
