# Стаття 26.

Командувач військ оперативного командування користується правом застосовувати заохочення щодо підлеглих прапорщиків та мічманів в повному обсязі цього Статуту, крім пунктів "д" і "е" статті 23 цього Статуту.

( Стаття 26 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )

Заохочення, які застосовують до офіцерів

( Назва глави із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
