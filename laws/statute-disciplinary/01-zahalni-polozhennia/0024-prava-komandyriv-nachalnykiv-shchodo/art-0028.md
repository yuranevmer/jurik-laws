# Стаття 28.

У військових навчальних закладах, крім застосування заохочень, визначених у статті 27 цього Статуту, застосовується занесення на Дошку пошани прізвищ, які закінчили військові навчальні заклади із золотою медаллю.

( Стаття 28 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )

Права командирів (начальників) щодо застосування заохочень до підлеглих офіцерів

( Назва глави із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
