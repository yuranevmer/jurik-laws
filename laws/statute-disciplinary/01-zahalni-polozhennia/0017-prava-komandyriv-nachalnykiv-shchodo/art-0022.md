# Стаття 22.

Командир дивізії, командувач корпусу, командувач військ оперативного командування щодо підлеглих рядових (матросів), сержантів (старшин) користуються правом застосовувати заохочення в повному обсязі цього Статуту, крім пункту "і" статті 15 цього Статуту.

( Стаття 22 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
