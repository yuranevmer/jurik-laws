# Стаття 69.

На вищих офіцерів можуть бути накладені такі дисциплінарні стягнення: ( Абзац перший статті 69 в редакції Закону N 1420-IV ( 1420-15 ) від 03.02.2004 )

а) зауваження;

б) догана;

в) сувора догана;

г) попередження про неповну службову відповідність;

д) пониження у посаді.
