# Стаття 74.

Начальник Генерального штабу Збройних Сил України, заступники Міністра оборони України, головнокомандувачі видів Збройних Сил України, крім прав, якими наділено командувача військ оперативного командування, мають право понижувати у посаді офіцерів від заступників командирів полків, старших помічників командирів кораблів 1 рангу, відповідних їм і нижчих.

( Стаття 74 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
