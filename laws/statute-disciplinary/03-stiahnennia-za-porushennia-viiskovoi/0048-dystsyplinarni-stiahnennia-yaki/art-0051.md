# Стаття 51.

На сержантів (старшин), військової служби за контрактом, можуть бути накладені такі стягнення: ( Абзац перший статті 51 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )

а) зауваження;

б) догана;

в) сувора догана;

г) попередження про неповну службову відповідність;

( Пункт "д" статті 51 виключено на підставі Закону N 1420-IV ( 1420-15 ) від 03.02.2004 )

е) пониження в посаді; ( Пункт "е" статті 51 в редакції Закону N 1420-IV ( 1420-15 ) від 03.02.2004 )

є) пониження у військовому званні на один ступінь;

ж) пониження у військовому званні на один ступінь з переведенням на нижчу посаду;

з) позбавлення сержантського (старшинського) звання;

и) звільнення з військової служби за контрактом за службовою невідповідністю. ( Пункт "и" статті 51 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
