# Стаття 49.

На рядових (матросів), військової служби за контрактом, можуть бути накладені такі стягнення: ( Абзац перший статті 49 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )

а) зауваження;

б) догана;

в) сувора догана;

г) попередження про неповну службову відповідність;

д) призначення поза чергою в наряд на роботу - до 5 нарядів;

( Пункт "е" статті 49 виключено на підставі Закону N 1420-IV ( 1420-15 ) від 03.02.2004 )

є) позбавлення військового звання старший солдат (старший матрос);

ж) звільнення з військової служби за контрактом за службовою невідповідністю. ( Пункт "ж" статті 49 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
