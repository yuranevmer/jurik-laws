# Стаття 79.

На прапорщиків, мічманів, офіцерів, які перебувають у запасі або відставці та носять військову форму одягу, за вчинення правопорушення, що ганьбить військову честь і гідність військового звання, накладається стягнення у вигляді позбавлення права носіння військової форми одягу.

( Стаття 79 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
