# Стаття 57.

Командир роти (корабля 4 рангу) має право:

а) робити зауваження, оголошувати догану та сувору догану;

б) позбавляти рядових (матросів), сержантів (старшин) строкової військової служби чергового звільнення з розташування військової частини чи корабля на берег; ( Пункт "б" статті 57 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )

в) призначати рядових (матросів) поза чергою в наряд на роботу - до 5 нарядів;

( Пункт "г" статті 57 виключено на підставі Закону N 1420-IV ( 1420-15 ) від 03.02.2004 )
