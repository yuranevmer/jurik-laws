# Стаття 61.

Командувач військ оперативного командування, командувач корпусу щодо підлеглих рядових (матросів), сержантів (старшин) користуються правом накладати дисциплінарні стягнення в повному обсязі цього Статуту.

( Стаття 61 із змінами, внесеними згідно із Законом N 1420-IV ( 1420-15 ) від 03.02.2004 )
