# Стаття 23. Громадянин після звільнення з альтернативної служби протягом п'яти календарних днів зобов'язаний стати на облік у військовому комісаріаті за місцем проживання. У такий же строк громадянин стає на облік і у разі зміни місця проживання. ( Стаття 23 із змінами, внесеними згідно із Законом N 1720-IV ( 1720-15 ) від 18.05.2004 )
