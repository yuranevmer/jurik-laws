Верховна Рада України п о с т а н о в л я є:

Внести до Закону України “Про статус ветеранів війни, гарантії їх соціального захисту”

(Відомості Верховної Ради (ВВР), 1993, N 45, ст.425 ) ( Вводиться в дію Постановою ВР N 3552-XII ( 3552-12 ) від 22.10.93, ВВР, 1993, N 45, ст.426 ) ( Із змінами, внесеними згідно із Законами N 3898-XII ( 3898-12 ) від 01.02.94, ВВР, 1994, N 20, ст.120 N 458/95-ВР від 23.11.95, ВВР, 1995, N 44, ст.329 N 488/95-ВР від 22.12.95, ВВР, 1996, N 1, ст. 1 N 498/95-ВР від 22.12.95, ВВР, 1996, N 3, ст. 11 N 608/96-ВР від 17.12.96, ВВР, 1997, N 8, ст. 62 N 367-XIV ( 367-14 ) від 25.12.98, ВВР, 1999, N 24, ст.209 N 944-XIV ( 944-14 ) від 14.07.99, ВВР, 1999, N 38, ст.342 N 2349-III ( 2349-14 ) від 05.04.2001, ВВР, 2001, N 22, ст.106 N 52-IV ( 52-15 ) від 04.07.2002, ВВР, 2002, N 35, ст.263 N 231-IV ( 231-15 ) від 21.11.2002, ВВР, 2002, N 52, ст.379 )

наступні зміни:

1. частину першу пункту другого статті 9 після слів “… на курсах професійної підготовки…” викласти в наступній редакції: “.., навчались в школах, вищих і середніх спеціальних навчальних закладах, працювали в народному господарстві та на відбудові об'єктів господарського і культурного призначення або народились з 31 грудня 1932 року по 31 грудня 1944 року на території Союзу РСР”.

2. Абзац третій пункту другого статті 9 після слів “факт роботи” доповнити словом: “або навчання”, далі – за текстом;

3. Абзац четвертий пункту другого статті 9 вилучити;

4. Закон набуває чинності з 1 січня 2005 року.

5. Кабінету Міністрів України при підготовці Проект Закону України “Про Державний бюджет України на 2005 рік” передбачити необхідні витрати з Державного Бюджету України, пов’язані з набуттям чинності цього Закону.
