ЗАКОН УКРАЇНИ

“Про внесення змін до статті 116 Житлового кодексу

Української РСР (щодо заборони примусового виселення найбільш незахищених верств населення із жилих приміщень без надання інших жилих приміщень)”

З метою реалізації гарантованих статтею 47 Конституції України прав на житло та у зв'язку із невиконанням державою зобов'язань по вчасній виплаті заробітної плати, інших грошових виплат населенню, в тому числі заощаджень, низькій платоспроможності громадян, до ліквідації Кабінетом Міністрів України заборгованості населенню по заробітній платі, Верховна Рада України п о с т а н о в л я є:

1. Доповнити статтю 116 Житлового кодексу Української РСР (із змінами, внесеними згідно з Указами Президії Української РСР N 2204-11 від 12.05.86, ВВР 1986, N 21, ст.414, N 2444-11 від 27.06.86, ВВР 1986, N 27, ст.539, N 6757-11 від 25.10.88, ВВР 1988, N 45, ст.1070, N 660-12 від 28.01.91, ВВР 1991, N 9, ст. 89, Законами N 1993-12 від 18.12.91, ВВР 1992, N 12, ст.169, N 3187-12 від 06.05.93, ВВР 1993, N 24, ст.258,N 3718-12 від 16.12.93, ВВР 1994, N 3, ст. 15,N 287/95-ВР від 11.07.95, ВВР 1995, N 29, ст.218, Декретом КМ N 11-92 від 15.12.92, ВВР 1992, N 7, ст. 55 Законом N 1525-III ( 1525-14 ) від 02.03.2000, ВВР, 2000, N 20, ст. 150

частиною 4 наступного змісту:

“Не допускається виселення із належного їм житлового приміщення без надання іншого житла , ветеранів, учасників Великої Вітчизняної війни, пенсіонерів, інвалідів, недієздатних, безробітних, неповнолітніх осіб, або одиноких осіб, а також сімей, які мають неповнолітніх дітей , фактично отриманий сукупний доход яких не перевищує встановленого прожиткового мінімуму, якщо вони не мають іншого житлового приміщення, що відповідає державним будівельним нормам, у випадку несвоєчасної оплати наймачами вартості споживчих комунальних послуг за користування житлом та за утримання житла до погашення заборгованості перед громадянами по заробітній платні, соціальних виплатах та заощадженнях.

Підставою для виселення не може бути також відмова без поважних на те причин укласти відповідний договір про реструктуризацію боргу з надавачами комунальних послуг.”
