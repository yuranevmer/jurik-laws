# Законопроект № 2407-2 (IV скликання)

Про внесення змін і доповнень до статей 9, 10 Закону України "Про статус ветеранів війни, гарантії їх соціального захисту" (щодо переліку осіб)

- Ініціатори: Микола Янковський, Юлій Іоффе
- Статус: на розгляді (2005-01-14)

Проект

Вноситься народними депутатами України

Янковським М. А., Іоффе Ю. Я.

Закон України

Про внесення змін і доповнень до статей 9, 10 Закону України “ Про статус ветеранів війни, гарантій їх соціального захисту”.

Верховна Рада України постановляє:

І. Внести до Закону України“ Про статус ветеранів війни, гарантій їх соціального захисту”. (Відомості Верховної Ради України, 1993р., №45, ст..425 ( Із змінами, внесеними згідно із Законами N 3898-XII ( 3898-12 ) від 01.02.94, ВВР, 1994, N 20, ст.120; N 458/95-вр від 23.11.95, ВВР, 1995, N 44, ст.329 ; N 488/95-вр від 22.12.95, ВВР, 1996, N 1, ст. 1 ; N 498/95-вр від 22.12.95, ВВР, 1996, N 3, ст. 11 ; N 608/96-вр від 17.12.96, ВВР, 1997, N 8, ст. 62 ; N 367-XIV ( 367-14 ) від 25.12.98, ВВР, 1999, N 24, ст.209 N 944-XIV ( 944-14 ) від 14.07.99, ВВР, 1999, N 38, ст.342; N 2349-III ( 2349-14 ) від 05.04.2001, ВВР, 2001, N 22, ст.106 ; N 52-IV ( 52-15 ) від 04.07.2002, ВВР, 2002, N 35, ст.263 ; N 231-IV ( 231-15 ) від 21.11.2002, ВВР, 2002, N 52, ст.379 ) такі зміни і доповнення:

У тексті статті 9, п.1 слова “ та війни з імперіалістичною Японією 1941-1945 років” замінити словами “ 1941-1945 років та війни 1945 року з імперіалістичною Японією”.

У тексті статті 9, п.2, ч.1 слова “ та війни з імперіалістичною Японією 1941-1945 років” замінити словами “ 1941-1945 років та війни 1945 року з імперіалістичною Японією”.

У тексті статті 9, п.2, ч.2 слова “ які після 1945 року були переселені на територію України з території інших країн” замінити словами “ що працювали і були переселені після 9 вересня 1944 року на територію України території Польщі, та інших країн після 1945 року”

У тексті статті 9, п.2, ч.4 слова “ особам, які народились після 31 грудня 1932 року” замінити словами “ особам, які народились до 31 грудня 1934 року ( шкільний вік на початок Великої Вітчизняної війни 1941-1945 років)”.

Доповнити ст.10 чинного Закону пунктом 3., наступного змісту “дружин ( чоловіків) померлих партизанів, підпільників, та військо службовців, які проходили службу у військових підрозділах, частинах, штабах і установах, що входили до складу діючої армії в період Великої Вітчизняної війни 1941-1945років, та війни 1945 р. з імперіалістичною Японією і відзначені нагородами за цей період ( ордени чи медалі союзу РСР, окрім ювілейних), і які не одружились вдруге”.

ІІ. Прикінцеві положення.

1. Цей Закон набирає чинності з 1 січня 2004 року.

2. Кабінету Міністрів України:

протягом трьох місяців з дня набрання чинності цього Закону привести свої нормативно-правові акти у відповідність з чинним текстом;

передбачити у розрахунках до проекту Державного бюджету України на 2004 рік кошти на реалізацію дії чинного Закону.
