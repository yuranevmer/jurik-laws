# Законопроект № 2397-2 (IV скликання)

Про внесення змін і доповнень до статті 9 Закону України "Про статус ветеранів війни, гарантії їх соціального захисту" (щодо осіб, які після 1944 року були переселені на територію України)

- Ініціатори: Павло Качур

ЗАКОН УКРАЇНИ

“Про внесення змін і доповнень до статті 9 Закону України “Про статус ветеранів війни, гарантії їх соціального захисту”

Верховна Рада України постановляє:

1. Виключити з абзацу 2 п.2) статті 9 Закону України “Про статус ветеранів війни, гарантії їх соціального захисту” (Відомості Верховної Ради України, 1993р., №45, ст..425 ( Із змінами, внесеними згідно із Законами N 3898-XII ( 3898-12 ) від 01.02.94, ВВР, 1994, N 20, ст.120; N 458/95-вр від 23.11.95, ВВР, 1995, N 44, ст.329 ; N 488/95-вр від 22.12.95, ВВР, 1996, N 1, ст. 1 ; N 498/95-вр від 22.12.95, ВВР, 1996, N 3, ст. 11 ; N 608/96-вр від 17.12.96, ВВР, 1997, N 8, ст. 62 ; N 367-XIV ( 367-14 ) від 25.12.98, ВВР, 1999, N 24, ст.209 N 944-XIV ( 944-14 ) від 14.07.99, ВВР, 1999, N 38, ст.342; N 2349-III ( 2349-14 ) від 05.04.2001, ВВР, 2001, N 22, ст.106 ; N 52-IV ( 52-15 ) від 04.07.2002, ВВР, 2002, N 35, ст.263 ; N 231-IV ( 231-15 ) від 21.11.2002, ВВР, 2002, N 52, ст.379 ) положення “та особи, які після 1945 року були переселені на територію інших країн,” і викласти його у наступній редакції:

“До учасників війни належать також особи, які в період Великої Вітчизняної війни працювали на територіях, що після 1944 року ввійшли до складу колишнього Союзу РСР, а також громадяни, які за направлення державних органів колишнього Союзу СРС працювали в державах, союзницях СРСР.”

Абзац 2 п.5) ст. 9 Цього Закону доповнити і викласти у такій редакції:

“До учасників війни належать особи, які в період другої світової війни були насильно вивезені з територій інших держав, які після 1944 року ввійшли до складу колишнього Союзу РСР. Ті, які після звільнення з концтаборів, гетто, та інших місць примусового тримання були переселені на територію колишнього Союзу РСР, а також особи, які після 1944 року були насильно переселені на територію України з територій інших країн, незалежно від їхнього віку на момент переселення.”

2. . Цей Закон набирає чинності з дня його опублікування.

Народний депутат України Павло Качур
