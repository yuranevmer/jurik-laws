# Законопроект № 2397 (IV скликання)

Про внесення змін до пункту 2 статті 9 Закону України "Про статус ветеранів війни, гарантії їх соціального захисту" (щодо осіб, які після 9 вересня 1944 року були переселені на територію України)

- Зареєстровано: 2003-03-07
- Ініціатори: Юлія Тимошенко, Олександр Турчинов, Олег Білорус, Віктор Таран
- Статус: на розгляді (2003-07-09)
- Картка: http://w1.c1.rada.gov.ua/pls/zweb2/webproc4_1?pf3511=13497

---

проект вноситься народним депутатами України Ю.Тимошенко О.Турчиновим О.Білорусом В.Тараном (Тереном)

Закон України

“Про внесення змін до пункту 2 статті 9 Закону України “Про статус ветеранів війни, гарантії їх соціального захисту”

Верховна Рада України постановляє:

1. Внести Закону України “Про статус ветеранів війни, гарантії їх соціального захисту”

( Відомості Верховної Ради (ВВР), 1993, N 45, ст.425 )

( Із змінами, внесеними згідно із Законами N 3898-XII ( 3898-12 ) від 01.02.94, ВВР, 1994, N 20, ст.120, N 458/95-вр від 23.11.95, ВВР, 1995, N 44, ст.329, N 488/95-вр від 22.12.95, ВВР, 1996, N 1, ст. 1, N 498/95-вр від 22.12.95, ВВР, 1996, N 3, ст. 11, N 608/96-вр від 17.12.96, ВВР, 1997, N 8, ст. 62, N 367-XIV ( 367-14 ) від 25.12.98, ВВР, 1999, N 24, ст.209, N 944-XIV ( 944-14 ) від 14.07.99, ВВР, 1999, N 38, ст.342, N 2349-III ( 2349-14 ) від 05.04.2001, ВВР, 2001, N 22, ст.106, N 52-IV (52-15 ) від 04.07.2002, ВВР, 2002, N 35, ст.263 )

наступні зміни:

1. В абзаці 2 пункту 2 статті 9 слово і цифру “… після 1945” після слів: “..особи, які…” замінити на “… з 1944”, далі – за текстом.

2. Закон набуває чинності з дня його офіційного оприлюднення.
