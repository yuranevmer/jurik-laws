# Законопроект № 13709 (IX скликання)

Про внесення змін до Цивільного процесуального кодексу України, Господарського процесуального кодексу України та Кодексу адміністративного судочинства України щодо порядку початку відліку строків для отримання документів сторін по суті та з процесуальних питань

- Зареєстровано: 2025-08-28
- Ініціатори: Олександр Юрченко
- Статус: на розгляді (2025-09-01)
- Картка: https://itd.rada.gov.ua/billInfo/Bills/Card/57188

---

ПРОЕКТ вноситься народними депутатами України ЗАКОН УКРАЇНИ

«Про внесення змін до Цивільного процесуального кодексу України, Господарського процесуального кодексу України та Кодексу адміністративного судочинства України щодо порядку початку відліку строків для отримання документів сторін по суті та з процесуальних питань»

Верховна Рада України п о с т а н о в л я є:

1.Внести зміни до таких законодавчих актів України:

1) Цивільний процесуальний кодекс України (Відомості Верховної Ради України, 2017 р., № 48, ст. 436) доповнити новою статтею 1231 такого змісту:

«Стаття 123 1. Порядок початку відліку строків для отримання документів сторін по суті та з процесуальних питань 1. Відлік строків для отримання документів сторін по суті та з процесуальних питань здійснюється в порядку, визначеному цим Кодексом для вручення судового рішення.».

2) Господарський процесуальний кодекс України (Відомості Верховної Ради України, 2017 р., № 48, ст. 436) доповнити новою статтею 1161 такого змісту:

«Стаття 116 1. Порядок початку відліку строків для отримання документів сторін по суті та з процесуальних питань 1. Відлік строків для отримання документів сторін по суті та з процесуальних питань здійснюється в порядку, визначеному цим Кодексом для вручення судового рішення.».

3) Кодекс адміністративного судочинства України (Відомості Верховної Ради України, 2017 р., № 48, ст. 436) доповнити новою статтею 1201 такого змісту:

«Стаття 120 1. Порядок початку відліку строків для отримання документів сторін по суті та з процесуальних питань 1. Відлік строків для отримання документів сторін по суті та з процесуальних питань здійснюється в порядку, визначеному цим Кодексом для вручення судового рішення.».

2. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

Голова

Верховної Ради України Руслан СТЕФАНЧУК
