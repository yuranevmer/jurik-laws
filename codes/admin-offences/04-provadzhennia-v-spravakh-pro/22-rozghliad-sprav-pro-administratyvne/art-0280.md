# Стаття 280. Обставини, що підлягають з'ясуванню при розгляді справи про адміністративне правопорушення

Орган (посадова особа) при розгляді справи про адміністративне правопорушення зобов'язаний з'ясувати: чи було вчинено адміністративне правопорушення, чи винна дана особа в його вчиненні, чи підлягає вона адміністративній відповідальності, чи є обставини, що пом'якшують і обтяжують відповідальність, чи заподіяно майнову шкоду, чи є підстави для передачі матеріалів про адміністративне правопорушення на розгляд громадської організації, трудового колективу, а також з'ясувати інші обставини, що мають значення для правильного вирішення справи.

( Стаття 280 із змінами, внесеними згідно з Указом ПВР N 1117-11 від 16.10.85, Законом N 2342-III ( 2342-14 ) від 05.04.2001 )
