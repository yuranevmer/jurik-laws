# Стаття 253. Передача матеріалів прокурору, органу досудового слідства або дізнання

Якщо при розгляді справи орган (посадова особа) прийде до висновку, що в порушенні є ознаки злочину, він передає матеріали прокурору, органу досудового слідства або дізнання. ( Стаття 253 із змінами, внесеними згідно із Законом N 762-IV ( 762-15 ) від 15.05.2003 )
