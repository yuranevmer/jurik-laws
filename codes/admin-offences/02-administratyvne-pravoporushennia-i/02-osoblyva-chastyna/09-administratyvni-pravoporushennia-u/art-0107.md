# Стаття 107. Порушення правил щодо карантину тварин та інших ветеринарно-санітарних вимог

Порушення правил щодо карантину тварин, інших ветеринарно-санітарних вимог, передбачених Законом України "Про ветеринарну медицину" ( 2498-12 ), іншими актами законодавства, а також рішень органів місцевого самоврядування з питань боротьби з епізоотіями, -

тягне за собою накладення штрафу на громадян від 0,5 до одного неоподатковуваного мінімуму доходів громадян, на посадових осіб - у розмірі від трьох до шести неоподатковуваних мінімумів доходів громадян.

( Стаття 107 із змінами, внесеними згідно із Законами N 4045-12 від 25.02.94, N 55/97-ВР від 07.02.97, N 2342-III ( 2342-14 ) від 05.04.2001 )
