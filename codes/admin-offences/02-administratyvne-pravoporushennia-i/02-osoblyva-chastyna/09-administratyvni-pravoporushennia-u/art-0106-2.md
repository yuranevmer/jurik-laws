# Стаття 106-2. Незаконні посів та вирощування снотворного маку чи конопель

Незаконні посів або вирощування снотворного маку чи конопель -

тягнуть за собою накладення штрафу від вісімнадцяти до вісімдесяти восьми неоподатковуваних мінімумів доходів громадян з конфіскацією незаконно вирощуваних наркотиковмісних рослин.

( Доповнено статтею 106-2 згідно з Указом ПВР N 4452-11 від 21.08.87; із змінами, внесеними згідно із Законами N 64/95-ВР від 15.02.95, N 55/97-ВР від 07.02.97 )
