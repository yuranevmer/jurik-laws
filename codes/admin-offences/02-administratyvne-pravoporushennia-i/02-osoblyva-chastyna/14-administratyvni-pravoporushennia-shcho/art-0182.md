# Стаття 182. Порушення тиші в громадських місцях

Порушення тиші на вулицях, площах, у парках, гуртожитках, жилих будинках та інших громадських місцях у заборонений рішеннями сільських, селищних, міських рад час -

тягне за собою попередження або накладення штрафу від одного до трьох неоподатковуваних мінімумів доходів громадян.

( Стаття 182 із змінами, внесеними згідно із Законами N 55/97-ВР від 07.02.97, N 2342-III ( 2342-14 ) від 05.04.2001 )
