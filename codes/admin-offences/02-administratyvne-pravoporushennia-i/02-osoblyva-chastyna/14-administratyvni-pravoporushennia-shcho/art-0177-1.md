# Стаття 177-1. ( Стаття 177-1 виключена на підставі Закону N 2547-12 від 07.07.92 ) Продаж громадянами вина домашнього вироблення, що не відноситься до міцних спиртних напоїв

Продаж громадянами вина домашнього вироблення, що не відноситься до міцних спиртних напоїв -

тягне за собою накладення штрафу в розмірі до п'ятдесяти карбованців з конфіскацією вина домашнього вироблення.

( Доповнено статтею 177-1 згідно з Указом ПВР N 2444-11 від 27.06.86 )
