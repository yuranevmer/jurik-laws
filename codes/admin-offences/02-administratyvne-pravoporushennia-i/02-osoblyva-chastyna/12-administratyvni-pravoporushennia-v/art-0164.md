# Стаття 164. Порушення порядку заняття підприємницькою або господарською діяльністю

Заняття підприємницькою діяльністю без державної реєстрації або заняття господарською діяльністю без ліцензії, якщо її отримання передбачено законом -

тягне за собою накладення штрафу від трьох до восьми неоподатковуваних мінімумів доходів громадян з конфіскацією виготовленої продукції, знарядь виробництва і сировини чи без такої.

( Стаття 164 із змінами, внесеними згідно з Указом ПВР N 2444-11 від 27.06.86; Законами N 3888-12 від 28.01.94, N 55/97-ВР від 07.02.97, N 2342-III ( 2342-14 ) від 05.04.2001 )
