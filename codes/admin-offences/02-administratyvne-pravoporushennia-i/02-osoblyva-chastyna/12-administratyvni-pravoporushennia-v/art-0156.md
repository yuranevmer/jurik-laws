# Стаття 156. Порушення правил торгівлі спиртними напоями

Порушення працівниками підприємств і організацій торгівлі або громадського харчування правил торгівлі горілкою та іншими спиртними напоями -

тягне за собою накладення штрафу від двох до двадцяти мінімальних розмірів заробітної плати.

( Стаття 156 із змінами, внесеними згідно з Указом ПВР N 316-11 від 29.05.85, N 8918-11 від 07.03.90; Законом N 3683-12 від 15.12.93 )
