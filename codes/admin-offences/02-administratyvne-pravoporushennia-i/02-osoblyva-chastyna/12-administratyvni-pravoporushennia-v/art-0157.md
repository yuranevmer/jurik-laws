# Стаття 157. Дрібна спекуляція

Дрібна спекуляція, тобто скуповування та перепродаж з метою наживи товарів або інших предметів, на які встановлено державні роздрібні ціни, в підприємствах (організаціях) торгівлі, а так само інших підприємствах, що здійснюють реалізацію товарів або інших предметів населенню, якщо розмір наживи не перевищує двадцяти п'яти неоподатковуваних мінімумів доходів громадян, -

тягне за собою накладення штрафу від восьми до двадцяти п'яти неоподатковуваних мінімумів доходів громадян з конфіскацією предметів спекуляції та виручених грошей.

( Стаття 157 із змінами, внесеними згідно з Указами ПВР N 316-11 від 29.05.85 N 7445-11 від 27.04.89, N 8918-11 від 07.03.90; Законами N 1255-12 від 25.06.91, N 55/97-ВР від 07.02.97 )

( Статтю 158 виключено на підставі Закону N 2342-III ( 2342-14 ) від 05.04.2001 )
