# Стаття 95. Порушення правил і норм з ядерної та радіаційної безпеки при використанні джерел іонізуючого випромінювання

Порушення посадовими особами підприємств, установ, організацій незалежно від форм власності, громадянами - власниками підприємств чи уповноваженими ними особами правил і норм з ядерної та радіаційної безпеки при використанні джерел іонізуючого випромінювання -

тягне за собою накладення штрафу до п'ятнадцяти мінімальних розмірів заробітної плати.

( Стаття 95 із змінами, внесеними згідно із Законом N 8/95-ВР від 19.01.95 )
