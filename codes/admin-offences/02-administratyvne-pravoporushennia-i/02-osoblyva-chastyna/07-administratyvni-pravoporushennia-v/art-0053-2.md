# Стаття 53-2. Приховування або перекручення даних земельного кадастру

Перекручення даних державного земельного кадастру і приховування інформації про наявність земель запасу або резервного фонду -

тягнуть за собою накладення штрафу на посадову особу від трьох до десяти неоподатковуваних мінімумів доходів громадян.

( Кодекс доповнено статтею 53-2 згідно із Законом N 2977-12 від 03.02.93, із змінами, внесеним згідно із Законом N 55/97-ВР від 07.02.97 )
