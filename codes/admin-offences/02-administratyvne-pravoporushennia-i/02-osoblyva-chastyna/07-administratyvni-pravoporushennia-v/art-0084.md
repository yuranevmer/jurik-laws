# Стаття 84. ( Статтю 84 виключено на підставі Закону N 81/96-ВР від 06.03.96 ) Невиконання розпоряджень органів, що здійснюють контроль за охороною атмосферного повітря

Невиконання розпоряджень органів, що здійснюють державний контроль за охороною атмосферного повітря, про усунення порушень правил щодо охорони атмосферного повітря, -

тягне за собою накладення штрафу на громадян від 0,5 до одного мінімального розміру заробітної плати і на посадових осіб - від одного до 1,5 мінімального розміру заробітної плати.

( Стаття 84 із змінами, внесеними згідно з Указом ПВР N 1369-12 від 29.07.91; Законом N 3785-12 від 23.12.93 )
