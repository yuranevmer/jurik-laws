# Стаття 122-3. Перешкоджання проведенню огляду транспортних засобів

Перешкоджання проведенню працівником міліції огляду транспортних засобів у передбачених законом випадках -

тягне за собою накладення штрафу від одного до трьох мінімальних розмірів заробітної плати.

( Доповнено статтею 122-3 згідно з Указами ПВР N 1369-12 від 29.07.91, виключена на підставі Указу ПВР N 1818-12 від 15.11.91; доповнено статтею 122-3 згідно із Законом N 3785-12 від 23.12.93 )
