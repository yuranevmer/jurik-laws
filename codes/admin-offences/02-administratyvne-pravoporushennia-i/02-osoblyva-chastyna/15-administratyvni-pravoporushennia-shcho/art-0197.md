# Стаття 197. Проживання без паспорта або без прописки

Проживання громадян, зобов'язаних мати паспорт, без паспорта або за недійсним паспортом, проживання без прописки або реєстрації -

тягне за собою попередження або накладення штрафу до трьох мінімальних розмірів заробітної плати.

( Стаття 197 із змінами, внесеними згідно із Законом N 296/95-ВР від 11.07.95 )
