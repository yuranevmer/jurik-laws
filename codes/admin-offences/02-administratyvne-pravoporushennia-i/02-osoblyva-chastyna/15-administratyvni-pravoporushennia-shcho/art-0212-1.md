# Стаття 212-1. Повідомлення неправдивих відомостей органам рагсу

Утаювання обставин, що перешкоджають одруженню, або повідомлення завідомо неправдивих відомостей органам реєстрації актів громадянського стану -

тягне за собою накладення штрафу від одного до двох

неоподатковуваних мінімумів доходів громадян. ( Кодекс доповнено статтею 212-1 згідно із Законом N 2547-12 від 07.07.92, із змінами, внесеними згідно із Законами N 55/97-ВР від 07.02.97, N 2342-III ( 2342-14 ) від 05.04.2001 )
