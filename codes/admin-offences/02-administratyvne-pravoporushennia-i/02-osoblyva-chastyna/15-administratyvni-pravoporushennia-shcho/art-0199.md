# Стаття 199. Допущення проживання без паспорта або без прописки

Допущення особами, відповідальними за додержання правил паспортної системи, проживання громадян без паспортів або за недійсними паспортами чи без прописки або реєстрації, а так само допущення громадянами проживання у займаних ними жилих приміщеннях осіб без паспортів, без прописки або реєстрації -

тягнуть за собою попередження або накладення штрафу до трьох мінімальних розмірів заробітної плати.

( Стаття 199 із змінами, внесеними згідно із Законом N 296/95-ВР від 11.07.95 )
