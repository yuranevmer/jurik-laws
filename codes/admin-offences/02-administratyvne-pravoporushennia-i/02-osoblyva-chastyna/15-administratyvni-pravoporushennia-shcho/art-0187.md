# Стаття 187. Порушення правил адміністративного нагляду

Порушення правил адміністративного нагляду особами, щодо яких установлено такий нагляд, -

тягне за собою накладення штрафу від трьох до десяти неоподатковуваних мінімумів доходів громадян.

( Стаття 187 із змінами, внесеними згідно із Законом N 55/97-ВР від 07.02.97 )
