# Стаття 188-21. Ухилення від виконання або несвоєчасне виконання рішень Національної комісії регулювання електроенергетики України

Ухилення від виконання або несвоєчасне виконання рішень Національної комісії регулювання електроенергетики України -

тягне за собою попередження або накладення штрафу на посадових осіб від трьох до восьми неоподатковуваних мінімумів доходів громадян.

( Кодекс доповнено статтею 188-21 згідно із Законом N 2598-IV ( 2598-15 ) від 31.05.2005 )
