# Стаття 198. Умисне зіпсуття паспорта чи втрата його з необережності

Умисне зіпсуття паспорта чи недбале зберігання паспорта, що спричинило його втрату -

тягне за собою попередження або накладення штрафу до трьох мінімальних розмірів заробітної плати.

( Стаття 198 із змінами, внесеними згідно із Законом N 296/95-ВР від 11.07.95 )
