# Стаття 185-4. Злісне ухилення свідка, потерпілого, експерта, перекладача від явки до органів досудового слідства або дізнання

Злісне ухилення свідка, потерпілого, експерта, перекладача від явки до органів досудового слідства або дізнання -

тягне за собою накладення штрафу від трьох до восьми неоподатковуваних мінімумів доходів громадян.

( Доповнено статтею 185-4 згідно з Указом ПВР N 9166-11 від 04.05.90; із змінами, внесеними згідно з Указом ПВР N 647-12 від 18.01.91, Законами N 55/97-ВР від 07.02.97, N 762-IV ( 762-15 ) від 15.05.2003 )
