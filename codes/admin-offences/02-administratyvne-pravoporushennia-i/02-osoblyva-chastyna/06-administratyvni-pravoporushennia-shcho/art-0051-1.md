# Стаття 51-1. Ухилення від відшкодування майнової шкоди, заподіяної злочином підприємствам, установам, організаціям

Ухилення від відшкодування майнової шкоди, заподіяної злочином підприємствам, установам, організаціям, особи, зобов'язаної за вироком або рішенням суду відшкодувати таку шкоду, -

тягне за собою попередження, або накладення штрафу від трьох до семи неоподатковуваних мінімумів доходів громадян, або виправні роботи на строк до двох місяців з відрахуванням двадцяти процентів заробітку.

( Кодекс доповнено статтею 51-1 згідно з Указом ПВР N 2444-11 від 27.06.86, із змінами, внесеними згідно із Законами N 55/97-ВР від 07.02.97 )
