# Стаття 27. Штраф

Штраф, що накладається на громадян за адміністративні правопорушення, як правило, не може перевищувати десяти карбованців, а на посадових осіб - п'ятдесяти карбованців.

При необхідності підвищення відповідальності за окремі види адміністративних правопорушень законодавчими актами Союзу РСР і Української РСР може бути встановлено більш високі розміри штрафів.

( Стаття 27 із змінами, внесеними згідно з Указами ПВР N 2441-11 від 27.06.86, N 4134-11 від 12.06.87, N 6347-11 від 03.08.88, N 8918-11 від 07.03.90 )
