# Стаття 316. Закінчення провадження по виконанню постанови про конфіскацію предмета, грошей

Постанова про конфіскацію предмета, грошей з відміткою про виконання повертається до суду, який виніс постанову. ( Стаття 316 із змінами, внесеними згідно із Законами N 1255-12 від 25.06.91, N 2342-III ( 2342-14 ) від 05.04.2001 )
