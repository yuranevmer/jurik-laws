# Стаття 319. Порядок виконання постанови про позбавлення права полювання

Виконання постанови про позбавлення права полювання провадиться шляхом вилучення мисливського квитка.

У разі ухилення особи, позбавленої права полювання, від здачі мисливського квитка органи мисливського господарства, вилучення мисливського квитка провадять у встановленому порядку.

Порядок вилучення мисливського квитка встановлюється спеціально уповноваженим центральним органом виконавчої влади в галузі лісового господарства.

( Стаття 319 із змінами, внесеними згідно із Законами N 81/96-ВР від 06.03.96, N 2342-III ( 2342-14 ) від 05.04.2001 )
