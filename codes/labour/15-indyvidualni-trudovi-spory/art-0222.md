# Стаття 222. Порядок розгляду трудових спорів деяких категорій працівників

Особливості розгляду трудових спорів суддів, прокурорсько-слідчих працівників, а також працівників навчальних, наукових і інших установ прокуратури, які мають класні чини, встановлюється законодавством.

( Стаття 222 із змінами, внесеними згідно з Указами ПВР N 3866-08 від 05.06.75, N 4617-10 від 24.01.83; Законом N 2134-12 від 18.02.92 )
