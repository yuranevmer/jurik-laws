# Стаття 64. Необхідність одержання дозволу виборного органу первинної профспілкової організації (профспілкового представника) підприємства, установи, організації для проведення надурочних робіт

Надурочні роботи можуть провадитися лише з дозволу виборного органу первинної профспілкової організації (профспілкового представника) підприємства, установи, організації. ( Стаття 64 із змінами, внесеними згідно з Указом ПВР N 4617-10 від 24.01.83; Законом N 1096-IV ( 1096-15 ) від 10.07.2003 )
