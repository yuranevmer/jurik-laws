# Стаття 256. Пенсійне забезпечення

Працівники та члени їх сімей мають право на державне пенсійне забезпечення за віком, по інвалідності, у зв'язку із втратою годувальника, а також за вислугу років відповідно до закону.

( Глава XVII із змінами, внесеними згідно з Указами ПВР N 2048-08 від 18.09.73, N 2240-10 від 29.07.81, N 4617-10 від 24.01.83, із Законами N 871-12 від 20.03.91, N 3694-12 від 15.12.93, N 263/95-ВР від 05.07.95, в редакції Закону N 429-IV ( 429-15 ) від 16.01.2003 )
