# Стаття 103. Повідомлення працівників про запровадження нових або зміну чинних умов оплати праці

( Назва статті 103 із змінами, внесеними згідно із Законом N 871-12 від 20.03.91 )

Про запровадження нових або зміну чинних умов оплати праці власник або уповноважений ним орган повідомляє працівників не пізніш як за один місяць до їх запровадження.

( Стаття 103 із змінами, внесеними згідно з Указом ПВР N 2240-10 від 29.07.81 )
