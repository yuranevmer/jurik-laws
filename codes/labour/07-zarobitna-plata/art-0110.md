# Стаття 110. Оплата праці при невиконанні норм виробітку, браку і оплата часу простою

При невиконанні норм виробітку, виготовленні продукції, що виявилась браком, та простої, які мали місце не з вини працівника, оплата провадиться в розмірах, які визначаються законодавством. ( Стаття 110 із змінами, внесеними згідно із Законами N 3694-12 від 15.12.93, N 263/95-ВР від 05.07.95 )
